معمول للفوضى اللي بيعملها المطوّرين

المنظّفات العادية بتفضّي سلة المحذوفات وخلاص. المساحة الحقيقية راحت في worktrees منسية وطبقات Docker وnode_modules في كل مشروع نزّلته في حياتك.

كل worktree بحجمه وحالته

قائمة واحدة لكل الـ worktrees في كل المستودعات.

  • علامات لـ merged، وتعديلات مش متحفوظة، وكوميتات مش مرفوعة.
  • فلتر "Merged & clean" يطلّعلك اللي حذفه آمن.
  • احذف كذا واحد مرة واحدة، ومعاهم الفروع لو حابب.

ملفات البناء حسب المشروع وعمره

node_modules وbin وobj وdist وtarget و.next و.venv وغيرهم.

  • فلتر للمشاريع اللي ما اتلمستش من 30 أو 90 يوم.
  • أي مجلد فيه ملفات متتبّعة في git أو كود مكتوب بإيدك بيتساب تلقائيًا.
  • أول install أو build بعدها يرجّعها.

Docker

الـ build cache والصور والحاويات والـ volumes بأحجامها الحقيقية، وتنظيف بضغطة، وضغط قرص WSL بتاع Docker عشان المساحة ترجع لويندوز.

الكاش

npm وpnpm وYarn وNuGet وpip وGradle وMaven وPlaywright وTemp، وكمان بقايا تحديثات ويندوز عن طريق أداة Disk Cleanup نفسها.

كل الأقراص

وجّهه لفولدرات مشاريعك، أو شغّل مفتاح واحد يفحص كل الأقراص مع تقدّم مباشر.

جهازك

المعالج وكارت الشاشة بذاكرته الحقيقية وكل شريحة رام وكل قرص، مع أزرار نسخ. وبينبّهك لو الرام شغالة أقل من سرعتها.

معمول عشان ما تخسرش شغلك أبدًا

الحذف هو الجزء السهل. نضّفني متصمّم أساسًا عشان ما يحذفش الحاجة الغلط.

  • كل حذف بيقولك هيمسح إيه بالظبطرسالة تأكيد فيها الاسم والحجم قبل أي حاجة.
  • الشغل اللي مش متحفوظ محتاج موافقة زيادةتعديلات مش متعمل لها commit، أو كوميتات مش مرفوعة، أو قفل، أو حالة git ما اتقرتش: كلها بتعتبر خطر.
  • مراجعة تانية قبل الحذف مباشرةلو عدّلت في worktree بعد الفحص، بيتساب.
  • الكود بتاعك في أمانملفات البناء اللي جواها ملفات متتبّعة في git أو كود مكتوب بإيدك عمرها ما بتتمسح.
  • فولدرات النظام ممنوعةWindows وProgram Files وفولدر المستخدم وAppData مرفوضين من محرّك الحذف نفسه.
  • سريع، وقدامك، وبيكمّلالحذف بيشتغل في الخلفية بتقدّم مباشر، ولو قفلت البرنامج في النص بيكمّل أول ما تفتحه.
